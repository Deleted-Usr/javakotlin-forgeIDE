Markdown itself does not have a strict list of supported languages. Instead, it relies on the tool 
rendering the Markdown to recognize the language tags.

Most popular platforms—like GitHub, GitLab, VS Code, and Obsidian—use a powerful library 
called Prism.js or Highlight.js behind the scenes. Because of this, almost every programming,
scripting, or data language you can think of is supported!
## Popular Supported Languages

* Web Development: html, css, javascript (or js), typescript (or ts)
* General Programming: python (or py), c, csharp (or cs), go, rust (or rs), ruby (or rb)
* Data & Configuration: json, yaml (or yml), xml, toml, sql, csv
* Shell & DevOps: bash, shell (or sh), powershell (or ps1), dockerfile, makefile
* Documentation: markdown (or md), latex (or tex)

## Pro-Tip: Plain Text
If you want to display code or logs without any colors or syntax highlighting, you can use text or plaintext:

```plaintext
This is just normal text inside a code block.
No keywords will be highlighted.
```
