Useful IntelliJ Platform UI components

A curated visual reference to JetBrains’ reusable Swing layer. The Platform contains many specialised or internal JB* classes, so this page focuses on common controls and companion classes that are useful when understanding how IntelliJ builds UI.

Unlike FlatLaf Extras: these are not a small standalone look-and-feel jar. They belong to the IntelliJ Platform APIs and bring Platform services, utilities and compatibility constraints. For Forge, study their design ideas; do not copy classes into the project or add the entire Platform merely to obtain a nicer JList.
