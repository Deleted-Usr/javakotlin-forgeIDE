FlatLaf Extras components

A visual reference for the convenience subclasses in com.formdev.flatlaf.extras.components, plus the visual utilities supplied by the Extras artifact. Most Flat* subclasses look like their Swing parent: their purpose is type-safe access to FlatLaf client properties without repeating string keys.

Important: these are optional convenience wrappers, not replacements required by FlatLaf. A normal JButton still receives the FlatLaf appearance. Use FlatButton when its getters and setters make your code clearer.
