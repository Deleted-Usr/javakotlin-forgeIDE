Static methods that add prompt text, and a focus behaviour for it, to any JTextComponent — not only the JX ones. Its sibling BuddySupport docks small components inside a field's border, which is how JXSearchField is built.

Before you add the dependency

SwingX is in maintenance, not development. It came out of the SwingLabs project at Sun, and the widely used release is org.swinglabs.swingx:swingx-all:1.6.5-1. Active work stopped in the early 2010s, so expect no fixes and no new components — check the current state of the project before committing to it, since my information here has a cutoff.

It still works, and JXTreeTable, JXDatePicker and the Highlighter pipeline remain hard to replace. But a few of its ideas were absorbed into the JDK — Painters became part of Nimbus, and RowSorter arrived in Java 6 — so check what you actually need before taking the whole library.

Separate modules. The map components, JXMapViewer and JXMapKit, are not in swingx-core; they live in the swingx-ws / mapviewer artifacts and are usually taken via the maintained jxmapviewer2 fork instead. Not shown above, since they render tiles rather than chrome.
